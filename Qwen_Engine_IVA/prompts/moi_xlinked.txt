TASK:

1. If the backend pattern above is "XLR" (proband AB ~1.0, consistent with
   hemizygous male or homozygous female; mother AB ~0.5, consistent with an
   unaffected carrier): this is the classic X-linked recessive pattern.
   Examine the evidence for affected male relatives on the maternal side
   (uncles, maternal grandfather, maternal male cousins) — if present and
   consistent, apply PP1 [Supporting, +1] citing that pedigree pattern. If no
   such family-history evidence is available, state so explicitly and do not
   apply PP1.

2. If the backend pattern above is "XLD" (proband AB ~0.5, heterozygous):
   this pattern alone is NOT sufficient to confirm XLD — you must
   additionally confirm from the evidence that the MOTHER is described as
   clinically AFFECTED with a consistent phenotype (not just a carrier). If
   the evidence affirmatively supports the mother being affected, apply PP1
   [Supporting, +1] citing that cosegregation. If the evidence does not
   support (or is silent on) the mother's affected status, state this
   explicitly, do NOT apply PP1, and note that XLD cannot be confirmed from
   available evidence — the variant remains scored at its base level only.

3. If the backend pattern above is "uncertain": state that the X-linked
   segregation pattern cannot be determined from available allelic-balance
   data, and do not apply any additional criterion.
