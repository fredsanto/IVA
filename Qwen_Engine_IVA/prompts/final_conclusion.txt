STEP 1 — PHASE CHECK (mandatory, do this first, before choosing a model):
For every gene with two or more candidate variants, extract each variant's
parent-of-origin EXACTLY as written in its own per-variant conclusion's
Segregation/inheritance line, and write one line per variant in this literal
format:
  Phase check [GENE]: Variant A parent-of-origin = <mother/father/de novo/
  unknown>; Variant B parent-of-origin = <mother/father/de novo/unknown> →
  <SAME parent = CIS | DIFFERENT parents = TRANS | UNKNOWN>
Do this as plain string comparison of the two parent-of-origin values — do
not reason about anything else yet. You MUST write this line even if you
are confident of the answer.

Worked example (this exact pattern has caused errors before — copy this
reasoning pattern exactly):
  Variant 1 Segregation: "inherited from mother"
  Variant 2 Segregation: "inherited from mother"
  Phase check GENE: Variant 1 parent-of-origin = mother; Variant 2
  parent-of-origin = mother → SAME parent = CIS
  → Both variants sit on the single allele inherited from the mother. The
  allele inherited from the father is wild-type at both positions. This is
  NOT compound heterozygous, regardless of how strong each variant's
  individual ACMG evidence is or how well the gene's biallelic disease
  mechanism fits the phenotype. Do not use the COMPOUND HETEROZYGOUS model
  for this gene.

STEP 2 — Determine the inheritance model from the per-variant conclusions,
using the STEP 1 phase check result:
- COMPOUND HETEROZYGOUS / BIALLELIC RECESSIVE: two (or more) variants in the
  SAME gene, each with supporting evidence (ACMG classification of at least
  Likely Pathogenic, or VUS with strong supporting criteria), AND the STEP 1
  phase check for that gene concluded TRANS (or UNKNOWN — phase not stated).
  In this case ALL such variants are jointly required to explain the
  phenotype — do not rank one over the other or frame it as one variant
  being "superior" to the other. Both/all must be listed as co-causative.
  If the phase check concluded UNKNOWN, you may still use this model but
  must note the phase uncertainty in the Reasoning section.
  If the STEP 1 phase check for that gene concluded CIS, you MUST NOT use
  this model for that gene, no matter how strong the individual variant
  evidence or gene-disease mechanism looks — fall back to SINGLE CAUSATIVE
  VARIANT (pick the stronger of the two) or state the gene has insufficient
  biallelic evidence.
- SINGLE CAUSATIVE VARIANT: one dominant, de novo, or clearly strongest
  variant with no qualifying second allele in the same gene (including the
  case where STEP 1 found CIS phase for what looked like a compound-het
  pair). Only this case gets a single named variant.

SINGLE-HIT RECESSIVE CHECK (applies to every gene, including genes with only
one candidate variant — do this before finalizing section 2): for each
variant you are about to list as causative, check its own per-variant
conclusion's Inheritance check / Segregation / compound-het fields. If that
gene's inheritance mode is autosomal recessive (AR) or X-linked recessive
(XLR), the variant is heterozygous, and no second variant in that gene was
identified (no compound-het/trans partner, and the variant itself is not
homozygous) — do NOT list this variant as causative, no matter how strong
its individual ACMG classification is. Instead state that this gene has
insufficient evidence for recessive disease causation (single heterozygous
hit only) and exclude it from section 2. If no variant remains after this
check, section 2 must say so explicitly rather than naming an insufficient
variant. This check is independent of, and applied before, the compound-
heterozygous STEP 1/STEP 2 logic above (which only concerns genes with two
or more candidate variants).
